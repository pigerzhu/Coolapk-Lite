# Win10 Mobile 图片修复

维护：pigerzhu。保留上游作者及原许可证。

## 已验证结果

2026-10-14，Lumia 950，Windows 10 Mobile 15254.603，ARM32。
独立测试包0.0.3.1安装成功，设备门户启动HTTP200，进程运行。用户实际核对头像、动态配图与大图，反馈全部恢复。

## 修改

- 图片缓存使用独立HTTP客户端，不再携带API令牌与账户Cookie；设置图片Accept和酷安Referer，请求超时30秒，并发连接8。
- 缩略图仅对准确匹配image.coolapk.com的无查询参数/片段地址添加.s.jpg；保留已带缩略图后缀的地址，不误改相似域名。
- 图片异常写入LocalState/image-errors.log，只记录域名、异常类型与HRESULT，不记录完整URL或账户信息；日志超过256KiB时重新开始。
- 增加GitHub Actions ARM原生构建，匹配.NET Native2.2与新版框架程序集，手机manifest最低系统15063。
- 测试包采用独立名称Pigerzhu.CoolapkLite.Test、Publisher CN=pigerzhu、新PhoneProductId，显示“酷安 Lite 测试”，与原版并存。
